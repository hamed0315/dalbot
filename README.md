
# Dalbot - Bale Messenger Robot

A powerful and modular bot for the Bale messenger, built 100% in Go.

## 🛠 Tech Stack
- **Language:** Go 1.22
- **Database:** SQLite3
- **Architecture:** Clean Architecture (Handlers, Services, Models)

## 🚀 How to Run
1. Clone the repository.
2. Copy `.env.example` to `.env` (if available) and fill in your tokens.
3. Run `go mod tidy`
4. Run `go run main.go`
